📋 Mission 1: The Missing Person
Detective, we have a missing person case. Sarah Johnson was last seen on 2024-01-15. We need to find her information from our citizens database. Write a SQL query to retrieve all information about Sarah Johnson.

🗄️ Database Schema:

citizens table:
- id (INTEGER)
- first_name (TEXT)
- last_name (TEXT)
- age (INTEGER)
- address (TEXT)
- phone (TEXT)
- last_seen (DATE)
💡 Hint: Use SELECT * FROM citizens WHERE first_name = 'Sarah' AND last_name = 'Johnson';
